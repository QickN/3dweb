# 3D Web

Three.js experiment that renders a personal 3D scene with orbit controls, animated geometry,
custom text, and FBX model assets.

## Local Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run build
```

## Notes

The scene is intentionally lightweight and loads the bundled FBX assets directly through Vite.
Orbit controls are enabled so the camera can be moved around the scene.
